Bug ID: BUG-003

Bug Title: User required to login twice before accessing customer dashboard

Environment: Web browser(Chrome)

Steps to Reproduce:
  1. Navigate to Customer login page
  2.  Enter valid email address
  3. Enter valid password
  4. Click "Sign In"
  5. Observe system response and repeat login when propted

Expected Results:
  - Login is successful after one attempt
  - User is redirected directly to the Customer Dashboard

Actual Results:
  - User is successfully logged in on first attempt
  - Login page is displayed again
  - User is required to log in a second time
  - User is redirected to Customer dashboard after the second login

Severity: Medium
Priority: P3
